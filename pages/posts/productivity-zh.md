## 综合工具

- [DeepSeek Harness](https://www.deepseek.com/en/harness) - AI Agent，包含插件系统。
- [Rayburst](https://github.com/AnInsomniacy/rayburst) - Aria2 Next 下载引擎，Motrix 的替代品。
- [Raycast](https://www.raycast.com/) - 多功能工具，包含剪贴板历史、全局搜索，并支持扩展。
- [Tinycast](https://github.com/abue-ammar/tinycast) - 开源的 Raycast 替代品，仅支持 macOS。
- [capcap](https://github.com/realskyrin/capcap) - 仅支持 macOS 的开源截图工具，支持滚动截图（长图）。
- [Atoll](https://github.com/Ebullioscopic/Atoll) - 为 macOS 提供灵动岛（比首批 PROLED XDR 设备还早的设备可以安装）。

### 辅助工具

- [repomix](https://github.com/yamadashy/repomix) - 把你的代码库打包成对 AI 友好的格式。

### 本地自托管 LLM

- [Strata](https://github.com/Niko1221/Strata) - 让 LLM 能在单张游戏显卡上运行的推理框架。
- [BitNet](https://github.com/microsoft/BitNet) - 微软官方的 1-bit LLM 推理框架。

## 开发

### IDE/编辑器

- [Zed Editor](https://zed.dev/) - 轻量级代码编辑器，内置 AI Agent。
- [PyCharm](https://www.jetbrains.com/pycharm/) - JetBrains 出品的 Python IDE。

### 数据库相关

- [DBX](https://github.com/t8y2/dbx) - 轻量级跨平台数据库客户端，内置 MCP 支持。

## 远程连接工具

- [easytier](https://github.com/EasyTier/EasyTier) - 去中心化的 Mesh VPN，支持 WireGuard。
- [code-server](https://github.com/coder/code-server) - 网页版 VSCode，部署在服务器上，在浏览器中使用。
- [OpenSSH Server for Windows](https://github.com/PowerShell/Win32-OpenSSH) - 在 Windows 上轻松搭建 SSH 服务端。
- [noVNC](https://github.com/novnc/noVNC) - VNC 网页客户端。（用 Agent 快速配置：[我的 Skill](https://github.com/Vincent-the-gamer/skills/blob/main/skills/novnc)）

## 字体

- [Input](https://input.djr.com/) - 编程字体，我在编辑器和终端里使用 Input Mono。
