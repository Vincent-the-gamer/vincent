# 你的AI编程助手，是不是也经常"翻车"？

不知道你有没有这种体验——

你跟AI说："帮我重构一下这个模块。"它洋洋洒洒写了几百行，你定睛一看，完全不是你想要的东西。你让它修个Bug，它修完引入三个新Bug。你让它加个功能，代码是跑起来了，但你回头一看——这代码结构，简直是灾难现场。

如果你点头了，那你并不孤单。200K GitHub Star的开源项目——**Matt Pocock的Agent Skills**，就是为了解决这些"AI编程翻车现场"而生的。

Matt Pocock是谁？TypeScript社区顶流，TotalTypeScript创始人，YouTube上教TS的那个光头大佬。但他最近搞的这个Skills项目，跟TypeScript其实关系不大——它是一套给AI编程助手（Claude Code、Codex、Zed等等）用的"技能包"，目标就一句话：**让AI真正按工程标准写代码，而不是"抽风式编程"（Vibe Coding）**。

# 四个AI编程翻车场景，你中过几个？

Matt在项目README里把AI编程的失败模式总结成了四种，精准到令人窒息：

**翻车一：AI根本不知道你想要什么。** 你脑子里的那个完美方案，AI完全理解偏了。你让它写个用户认证，它给你整了个OAuth 2.0全家桶——你其实只是想要个邮箱+密码登录。

**翻车二：AI太啰嗦了。** 你让它解释项目里的一个概念，它用20个字能说清的事，非得写200字。久而久之，Token烧光了，你耐心也烧光了。

**翻车三：代码跑不起来。** AI写的代码看着像模像样，实际一跑就崩。没有测试、没有反馈循环，AI在"盲写"。

**翻车四：代码熵增失控。** AI写代码太快了，快到你来不及做设计。几个迭代下来，项目就变成了一个没人敢碰的"泥球"（Ball of Mud）。

这四种翻车场景背后，其实都在说同一件事：**AI加速了编码速度，但也放大了糟糕的工程习惯。你对工程规范有多敷衍，AI就会帮你放大多少倍。**

# 这20个Skill，本质上是一套"工程纪律"

Matt的Skills不是那种"写一个更好的Prompt"的技巧——它是一套把顶级工程师的工作方法，编码成AI可以直接执行的"技能"。

来看看几个核心Skill是怎么解决上述翻车的：

### `/grill-me` 和 `/grill-with-docs`——先"拷问"你，再动手

这是Matt最受欢迎的Skill。它的逻辑出奇地简单：**在AI动手写代码之前，先把你问个底朝天。**

> "你要实现的功能具体是什么？边界条件考虑了吗？如果用户输入为空怎么办？这个改动会影响哪些现有模块？你确定数据库schema不用改？"

这不是AI在抬杠，而是在做软件工程里最重要也最容易被跳过的一步——**需求对齐**。《程序员修炼之道》里说"没人真正知道自己想要什么"，这句话在AI时代更成立。

而`/grill-with-docs`更进一步：它不仅拷问你，还会帮你建立项目的**领域语言（Ubiquitous Language）**。比如，与其每次都说"课程里的一个课时被分配了文件系统中的实际位置"，不如统一定义为"物化级联（materialization cascade）"。术语统一了，AI的理解精准了，Token也省了。

**这就是所谓"共享语言"的力量——你和AI之间，终于开始说同一种话了。**

### `/tdd`——红-绿-重构，AI也得守规矩

很多开发者觉得TDD（测试驱动开发）太慢，AI时代就更没人用了。但Matt的观点正好相反：**正是因为AI写代码快，你才更需要测试。**

`/tdd` Skill强制AI遵循"先写一个会失败的测试→写代码让测试通过→重构"的标准循环。这意味着AI每写一行代码，都能立刻得到反馈——测试绿了就是对了，红了就是错了。没有测试的AI编程，就像蒙着眼睛开车。

### `/improve-codebase-architecture`——AI酿的"泥球"，AI自己来解

这个Skill可能是整个项目里最"哲学"的一个。你运行它之后，它会扫描你的代码库，找出一堆可以优化的架构问题，生成一个可视化的HTML报告，然后跟你逐一讨论哪些值得改。

它的背后是一个深刻的原则——John Ousterhout在《软件设计的哲学》里说的："最好的模块是'深'的——用简单的接口封装大量的行为。" `/improve-codebase-architecture`就是在帮你和AI一起，往这个方向迭代。

> 软件工程四大基本功——对齐、沟通、反馈、设计——在AI时代不是过时了，而是前所未有地重要。

# 30秒装好，立刻开干

这个项目最友好的地方在于：安装真的就30秒。

**如果你用Claude Code：**

```shell
claude plugins install mattpocock-skills
```

**如果你用Zed、Codex或其他Agent：**

```shell
npx skills@latest add mattpocock/skills
```

它会让你选你要哪些Skill、用什么Issue Tracker（GitHub / Linear / 本地文件），然后运行`/setup-matt-pocock-skills`初始化一下，完事。

首次使用建议：打开你的Agent，先跑一个`/grill-with-docs`，感受一下被AI"拷问"是什么体验。相信我，问完之后你会发现自己之前对需求的理解有多模糊。
